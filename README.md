# 书刊18 资本的温度干部资本市场读本

> 干部读本·资本市场

## 关于本书

写给干部的资本市场读本，核心命题一句：创新驱动经济里，识别和支持硬科技企业的人需要理解资本市场机制。从合肥押注京东方与蔚来开篇，逐章讲解一级市场机制：风险投资如何定价不确定性、杠杆收购的双刃、并购重组制度逻辑、地方政府产业基金运作。美式金融教训以案例打散各章作为对照。

## 篇目

- 导论：合肥夜里那盏灯
- 第1章 成长期资本市场：从捕鲸到硅谷再到合肥
- 第2章 看懂美式金融：杠杆、衍生品与监管套利
- 第三章 金融向善：中国视角的成长期资本市场
- 第4章 投资人气质：方法论、财务嗅觉、产业洞察
- 第5章 风险投资：发现价值的服务
- 第6章 私募股权与产业并购：价值创造还是杠杆套利
- 第7章 投行功能：上市、并购与重组
- 第8章 政府引导基金与国资平台：耐心资本的国家形态
- 第九章 多层次资本市场：科创板、北交所、大基金
- 第10章 种子期:从实验室到中试
- 第11章 成长期：量产、扩张与产业链构建
- 第12章 Pre-IPO与上市：注册制窗口与估值
- 第13章 成熟期与集团化：并购整合、产业集团与转型再生
- 第15章 半导体：举国之芯
- 第16章 新能源：从电池到整车
- 第17章 生物医药：漫长回报期与突破
- 第18章 人工智能:从CV到大模型
- 第19章 商业航天与量子：星辰大海
- 第20章 高端装备与新材料：工业母机
- 第21章 合肥：最敢下注的政府
- 第22章 深圳：市场化国资的范本
- 第23章 杭州：民营资本与平台转型
- 第二十四章 其他标杆：苏州/上海/北京/武汉/西安/成都
- 第25章 引导基金的考核与激励
- 第26章 监管底线：防范杠杆滥用与影子银行
- 第27章 人才培养：懂行的干部怎么养
- 第28章 国际化：走出去与引进来
- 结语：给未来的干部
